# IQC Inspection Control Dashboard

Dashboard de controle de inspeção de entrada de material — Foxconn.

## Arquivos
- `index.html` — página principal
- `style.css`  — estilos (tema dark industrial)
- `app.js`     — lógica completa (parsing Excel, charts, filtros)

## Como usar
Coloque os 3 arquivos na mesma pasta e abra `index.html` no Chrome.

## GitHub Pages
Settings → Pages → Branch main → Save

## Dependências (CDN, sem instalação)
- Chart.js 4.4.4
- SheetJS 0.20.3
- Google Fonts
